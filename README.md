# Tufts FastQC

[![GitHub License](https://img.shields.io/badge/license-MIT-green.svg)](https://opensource.org/licenses/MIT)

An Open OnDemand Batch Connect app that launches the
[FastQC](https://www.bioinformatics.babraham.ac.uk/projects/fastqc/) GUI in an
XFCE desktop (VNC) on the Tufts HPC cluster (`pax`) through a Slurm batch job.

## Features

- Partition, core, memory, and walltime fields are generated by the shared
  site resource discovery partial, so limits match the selected partition.
- Optional **Request priority start** checkbox submits the job with
  `--qos=interactive`. While checked, `form.js` caps the form to the
  interactive QOS limits (4 hours, 16 cores, 64 GB memory, 1 job per user)
  and shows a notice listing them.
- Optional email notification when the session starts
  (sent to `$USER@tufts.edu`).
- Selectable FastQC version (currently `0.12.1`).

## Repository Layout

- `manifest.yml`: app metadata (Interactive Apps → Bioinformatics).
- `form.yml.erb`: launch form; renders resource fields from
  `/etc/ood/config/apps/dashboard/batch_connect/partials/resource_discovery.erb`.
- `form.js`: dynamic form logic (resource limits, interactive QOS caps).
- `submit.yml.erb`: Slurm submission options (VNC template).
- `template/before.sh.erb`: pre-launch setup.
- `template/script.sh.erb`: starts the XFCE session and launches FastQC.

## Requirements

On the **compute nodes**:

- Lmod (or compatible) with modules `openjdk` and `fastqc/<version>`
- XFCE (`xfce4-session`, `xfdesktop`, `xfconf-query`) and `dbus-launch`
- TurboVNC and websockify for Batch Connect VNC sessions

On the **OnDemand host**:

- The resource discovery partial at the path above.

## Adding a FastQC Version

1. Install the module as `fastqc/<version>` on the cluster.
2. Add the version to the `version` options in `form.yml.erb`.

## Install / Update

Clone into the OnDemand apps directory (system or sandbox) and check out the
desired branch or tag:

```sh
git clone git@github.com:TuftsRT/ood-fastqc.git
cd ood-fastqc
git checkout <tag/branch>
```

To update, `git pull` (or `git fetch && git checkout <tag/branch>`). This is
not a Passenger app, so no restart is needed.
